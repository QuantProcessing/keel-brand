# Keel brand

Public brand assets for the Keel products, served from here so that pages outside
the products (the Cloudflare Access sign-in page) can load them.

| File | Use |
|---|---|
| `logo/keel.svg`, `logo/keel-256.png` | Keel — the family mark: a hull's cross-section narrowing into a keel. Used on the shared sign-in page |
| `logo/keeluni.svg` | KeelUni — CEX / DEX trading and arbitrage |
| `logo/keelcue.svg` | KeelCue — signal trading |

All marks share one tile: 28 × 28 in a 32 viewBox, radius 8, `#50d2c1`, the figure cut out
as a mask so it reads on any background. Background `#1b2429`, text `#f6fefd`.

Nothing here is secret. Do not add anything that is.
