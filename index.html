Principles

Trading tools should make you calmer, not more anxious.

These are not slogans. They are rules built into every product.

01

Self-hosted

The products run on your own server or computer. We hold no funds, handle no keys, and cannot see your accounts.

02

Write-only credentials

API keys are verified with the exchange, then encrypted; no endpoint or log ever returns them. Private keys stay on the host that uses them.

03

Simulate, then go live

Simulation by default: strategies decide and record as usual but sign and send nothing. Going live is your explicit choice.

04

Honest state

Unknown is shown as unknown, never as success. When an order's outcome is unclear, it is looked up — never placed twice.
