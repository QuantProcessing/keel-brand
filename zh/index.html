Keel 產品線 · 鴻驍數科

從信號到執行，
一條龍骨貫穿。

Keel 是一組交易軟體工具：在你連接的每個市場執行，按規則觸發，從多個來源發現信號。全部運行在你自己的環境裡，資金與金鑰從不離開你的手。

KeelUni

一站式交易終端

自託管CEX + DEX現貨 · 永續 · 期權

一個終端連接你所有的交易所：看行情、下單、對沖、做價差，倉位與資金一屏看清。

  • 資金與預警各帳戶的餘額、欠款與劃轉集中管理；交易所價格偏離與充提異常即時推送。

觸發

KeelCue

鏈上信號交易與自動化倉位管理

自託管EVM 鏈策略化

信號一到，按你寫下的規則動手；買到之後，倉位的定價、止盈止損與退出也由它全程管理。

  • 多種信號源指定錢包的成交、跨鏈資金到帳、代幣上線等事件，直接從鏈上讀取。
  • 規則先於成交每個信號按策略檢查稅率、可賣出性、市值與滑點，不符合就跳過並寫明原因。
  • 倉位全程管理止盈止損、持倉時間、按比例跟隨賣出；價格直接取自鏈上流動性池。
  • 完整可追溯每筆記錄從信號、檢查、報價、模擬到回執逐步呈現，未執行的步驟明確標出。

KeelSonar

多源交易信號側欄

Chrome 擴充功能即時AI 調查

把散落在各處的預警與快訊收進一個常駐側欄，從發現標的到打開交易頁，只隔一次點擊。

  • 多源匯集社群預警、交易所公告、新聞快訊並排或合併成一列，各自篩選與捲動。

原則

交易工具應該讓你更放心，而不是更擔心。

以下不是宣傳口號，而是寫在每個產品裡的規則。

01

自託管

產品部署在你自己的伺服器或電腦上。我們不託管資金，不經手私鑰，也看不到你的帳戶。

02

憑證只寫不讀

API Key 經交易所驗證後加密保存，任何介面與日誌都不回傳。私鑰只留在執行它的主機上。

03

先模擬，再實盤

預設模擬運行：策略照常判斷、照常記錄，但不簽名、不下單。切換實盤需要你明確設定。

04

狀態如實

結果未知就寫未知，從不把缺失當作成功；訂單結果不明時只查詢，不重複下單。

展望

龍骨之上，還有更多。

我們沿著同一條鏈路繼續延伸：讓信號更聰明，讓風險更早被看見，讓團隊也能用上。

KeelAgent

研發中

信號交易 Agent

一個懂交易的 AI 代理：讀取 KeelSonar 的信號，自動做敘事與鏈上調查，按你的風險偏好給出交易方案；經你確認，或在你設定的權限內，交由 KeelCue 與 KeelUni 執行。每一步推理都留有記錄。

KeelWatch

內測中

交易所與鏈上風險預警

交易所價格偏離全市場、充提暫停、錢包異常流出時，第一時間按級別推送到手機，並判斷跨所與鏈上套利是否可執行。保護資產，也不錯過機會。

KeelLab

規劃中

策略研究與回測

同一份策略程式碼，在歷史數據上回測、在模擬盤驗證、在實盤運行，三者行為一致。用真實的成交與滑點數據評估策略，而不是理想曲線。

KeelDesk

規劃中
